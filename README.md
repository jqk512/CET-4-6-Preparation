# CET-4/6 Preparation

一个把英语四、六级真题练习、听力播放和错题复盘放在一起的交互式学习网站。

**在线使用：** [GitHub Pages](https://jqk512.github.io/CET-4-6-Preparation/) · [备用入口](https://cet46-preparation-jqk-2026.just-elf-6358.chatgpt.site/)

## 本站功能

- 收录四级、六级共 **44 套试卷、2070 道客观题**，按年份、月份和套卷分别整理。
- 支持听力、选词填空、长篇匹配和仔细阅读在线作答；写作与翻译提供原题练习。
- 提供答题进度、交卷判分、逐题回看和按试卷整理的错题本。
- 练习记录保存在当前浏览器，支持导出和导入备份；无需注册账号。
- 首页、选卷和错题本使用独立设计的动画与交互；进入做题页面后关闭交互音效。

## 代码架构

本站是无需后端的静态网站，界面由原生 HTML、CSS 和 JavaScript 构成。

| 目录 / 文件 | 用途 |
| --- | --- |
| `local/` | 页面、样式、交互代码和本地开发入口 |
| `local/bank/` | 按级别、日期、套卷分开的 JSON 题库与题目补充数据 |
| `local/assets/` | Logo、听力音频等页面资源 |
| `scripts/` | 题库整理、校验和静态发布脚本 |
| `dist/` | 由 `scripts/prepare_hosted.py` 生成的发布目录 |

本地预览运行 `npm run dev`，然后打开 `http://localhost:4173`。作答记录保存在浏览器的 `localStorage`；清除站点数据前请先导出备份。

## 题库来源与使用说明

题库主要依据我在**拼多多小店购买的网盘资源**整理。我按考试级别、年份、月份和套卷重新录入 JSON，并检查题目、答案与音频的对应关系。本站的页面视觉与交互由本项目独立设计和实现。

真题题目、解析与音频的版权归各自权利人，**仅供个人学习使用**，请勿用于商业用途或大规模传播。

部分早期试卷的音频仍从参考项目的托管地址播放；早期参考代码的许可文本保留在 [SOURCE-LICENSE](SOURCE-LICENSE)。该协议不适用于真题、解析和音频。
