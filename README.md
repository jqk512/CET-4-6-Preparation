# CET-4/6 Preparation

[Open the practice site](https://jqk512.github.io/CET-4-6-Preparation/)

A static CET-4 and CET-6 exam practice site with 25 papers, 1,174 objective questions, writing and translation prompts, and a browser-local mistake review. Your answers and review history stay in this browser and can be exported as a backup.

To preview locally, run `python3 -m http.server 4173` in this repository and open http://localhost:4173. This repository contains the GitHub Pages build; original PDFs and MP3 files are not included. The March 2023 CET-4 listening audio is hosted by the [public companion site](https://cet46-preparation-jqk-2026.just-elf-6358.chatgpt.site/). Other published listening audio is requested from the original project's public library.

Question resources and the original resource index are based on [Couldyyy9/cet-website](https://github.com/couldyyy9/cet-website). Its source license is copied in [SOURCE-LICENSE](SOURCE-LICENSE).
